# Revue du skill EDoctor

Revue manuelle du 1 octobre 2026. Le validateur `quick_validate.py` de `skill-creator` accepte la copie versionnée du skill. Les scénarios suivants vérifient que ses instructions renvoient aux bonnes références et restent cohérentes avec le code. Ils ne constituent pas une certification automatique de futures interventions.

| Scénario                   | Instructions applicables                                                                                                                                     | Résultat de la revue                                                                                                                                                                                                                                    |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Ajouter une catégorie      | `design.md` exige de maintenir ensemble mapping, routes, facettes, taxonomie d'import et tests mobiles. `catalog.md` fixe les quatorze catégories actuelles. | Une catégorie supplémentaire doit être une décision explicite de périmètre. Réutiliser Shell, Catalog et ProductCard ; conserver le violet et les unités homogènes. Ne pas créer une quinzième catégorie pour masquer une référence manquante.          |
| Préparer une fiche produit | `catalog.md` exige un modèle exact, des sources datées, les données inconnues explicites, les droits des photos et un import en brouillon.                   | La recherche des processeurs distingue les prix observés, les prix de vente et le stock EDoctor. Les images absentes restent signalées. Une famille de portables sans configuration exacte ne suffit pas.                                               |
| Modifier une page publique | `design.md` indique les tokens et composants partagés ; `operations.md` impose ISR, isolation des sessions et mesure réelle du rendu.                        | La correction PostCSS a été suivie d'un test de police/couleur, de captures Chromium isolées et de trois mesures mobiles par URL. Des scores obtenus sans styles ont été écartés. Les mesures sans catalogue ne certifient pas les pages avec produits. |

Les références couvrent les trois scénarios sans demander un accès à la production. Le skill ne remplace pas les validations avec WooCommerce, le test d'import ni les autorisations de déploiement.
